# 6 Importances · Fun Mix

A small Windows 10-inspired, browser-based collection of six mini tools. Open `index.html` in a modern browser to use it. No installation or account is required.

## Included tools
1. **Smart Calc** — evaluates basic arithmetic expressions.
2. **Temp Convert** — converts Celsius, Fahrenheit, and Kelvin.
3. **Password Gen** — creates a random password-like string.
4. **Tip + Split** — calculates a tip and splits a bill.
5. **Guess Number** — a number guessing game.
6. **Unit Converter** — converts common length units.

## Run locally
1. Download or clone this project.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. Use **Previous / Next** or the left/right arrow keys to move between tools.
