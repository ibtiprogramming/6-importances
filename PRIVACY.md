# Privacy Policy — 6 Importances · Fun Mix

**Last updated: 6 November 2026**

6 Importances · Fun Mix is a browser-based mini-tools demo. This project does not provide user accounts, a server-side application backend, analytics, advertising trackers, or a form that sends the values you enter to the project author. The calculations and game logic run in your browser.

## Information entered into the tools
Values entered into Smart Calc, Temp Convert, Tip + Split, Guess Number, and Unit Converter are processed locally by the page for the requested calculation or game. The page contains no code intended to upload those values to the project author.

The Password Gen tool creates a string in the browser. It uses `Math.random()`, which is **not** a cryptographically secure random-number generator. Do not rely on it for important, financial, or highly sensitive accounts.

## Third-party resource
The page loads its Font Awesome icon stylesheet from **cdnjs.cloudflare.com**. When the browser requests that stylesheet, the CDN may receive ordinary connection information such as your IP address, browser information, and request metadata. The CDN is operated by a third party and is subject to its own privacy practices. The app's icons may not load if you are offline.

## Storage and sharing
The project code does not intentionally save tool inputs to local storage, cookies, or a project-owned database. Your browser may retain ordinary browsing data according to your own browser settings. The app does not automatically publish or share the values you type.

## Children and personal information
Do not enter passwords, private messages, personal identifiers, or other sensitive information into this demo. The app does not need personal information to work.

## Changes and contact
If this project is updated, this policy may also be updated. For questions, use the contact method provided by the project maintainer on the repository page where you obtained the app.

This policy describes the included HTML file as packaged. If you add hosting services, analytics, forms, external APIs, advertising, or other third-party scripts later, review and update this policy before publishing. This document is project information, not legal advice.
