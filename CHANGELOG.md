# Changelog

Notable changes to CleanText are recorded here.

## Unreleased — interface and usability upgrade

- Added live word and character counts for the source text.
- Added one-click example loading and editor clearing.
- Added a download action for cleaned text (`.txt`).
- Added a light/dark theme switch.
- Improved small-screen layout and visible keyboard focus states.
- Added keyboard activation and pressed-state announcements for view tabs.
- Expanded the README with setup, feature, privacy, and limitation guidance.

## Previous version

- Added tokenization, English stop-word filtering, protected negations, and lightweight stemming.
- Added approximate POS tags and document-term matrix views.
- Added CSV export and copy-clean actions.
